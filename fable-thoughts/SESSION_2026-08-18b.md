## Are days genuinely different? (the seeding question)

Pre-registered battery on 364 complete days:

| test | result | verdict |
|---|---|---|
| Exact duplicate 24-hour sign-patterns | 0 of 364 | no sequence reuse |
| Pairwise hamming distance between day shapes | 0.4923 vs 0.480 null | no clustering |
| Daily return autocorr lag1-3 | −0.040 / −0.022 / −0.080 (noise 0.103) | independent |
| P(same sign next day) | 0.696 vs base 0.822 (base rate dominates) | no signal |
| Prev-day sign → next-day hourly mean | +0.419% vs +0.382% (t≈0.9) | no carryover |
| Deviation-from-schedule → next-hour return | +0.074%/h, t=+1.46; P(up) 57.0% vs 58.8% | weak, sub-threshold |

**Days are independent draws. No seeding leak, no day-shape memory, no schedule
mean-reversion strong enough to clear a payout.** The generator appears to draw a fresh
random walk at each reset with the same fixed drift law — the only things that persist
day to day are the PARAMETERS (drift, vol), not the path.
